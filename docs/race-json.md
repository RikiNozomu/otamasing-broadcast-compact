# รูปแบบไฟล์ JSON ของรายการแข่ง

ไฟล์นี้ใช้ทั้งตอน **นำเข้า JSON** (เลือกไฟล์ หรือกด **วาง JSON** แล้ววางข้อความ) และ **ส่งออก** (บันทึกไฟล์ หรือ **คัดลอก JSON**; dock ใน OBS บันทึกไฟล์ไม่ได้ ให้ใช้คัดลอก) ใน dock ถ้าจะให้ Claude แปลงข้อมูลจากหน้าเว็บ (เช่น netkeiba) ให้แปะเอกสารนี้ หรือ [`schema/race.schema.json`](../schema/race.schema.json) ไปด้วย แล้วบอกว่า "แปลงเป็น JSON ตามรูปแบบนี้"

- ไฟล์ทั้งไฟล์ต้องเป็น object ที่มี `races` (อาร์เรย์ของรายการ) และ/หรือ `horses` (ข้อมูลม้า ดู [ข้อมูลม้า](#ข้อมูลม้า-horses)) หรือจะเป็นอาร์เรย์ของรายการเฉยๆ ก็ได้
- ช่องที่ไม่ใส่จะใช้ค่าเริ่มต้นในตาราง ช่องที่ **ต้องมี** มีแค่ `date`, `name` และ `runners`
- ตอนนำเข้าเลือกได้ว่าจะ **เพิ่มต่อ** (รายการที่ วัน + สนาม + เลขรอบ ตรงกับของเดิมจะถูกแทนที่) หรือ **แทนที่ทั้งหมด**
- รูป (รูปด้านซ้ายของการ์ดและหน้าผล, BG หน้าแรก) ไม่อยู่ในไฟล์ ต้องเลือกใหม่ในเครื่องที่ใช้

ตัวอย่างเต็มอยู่ที่ [`example-race.json`](example-race.json)

## ระดับไฟล์

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `version` | `1` | `1` | รุ่นของรูปแบบไฟล์ |
| `races` | อาร์เรย์ของรายการ | `[]` | รายการแข่ง เรียงตามลำดับที่จะแสดงในหน้าแรก (ต้องมี `races` หรือ `horses` อย่างน้อยอย่างหนึ่ง) |
| `horses` | อาร์เรย์ของม้า | `[]` | ข้อมูลม้าของแท็บ **ม้า** |
| `horseSettings` | object | – | `currency`: สกุลเงินรางวัลที่แสดง (`"own"` = ตามม้าแต่ละตัว หรือรหัสสกุลเงิน), `rates`: ค่าของ 1 หน่วยเป็น USD เช่น `{ "JPY": 0.0066 }` |
| `home` | object | – | ค่าของหน้าแรก: `title`, `subtitle` (วันที่), `highlight` (id ของรายการที่ไฮไลต์ หรือ `null`), `page` (หน้าที่แสดง เริ่มที่ 0, หน้าละ 8 รายการ) |
| `active` | string | – | สิ่งที่ขึ้นจอ (ใช้ตอนแทนที่ทั้งหมด): `"home"` หน้าแรก, `"blank"` หน้าเปล่า, `id` ของรายการ (การ์ดรายชื่อม้า), `"<id>:result"` (หน้าผลของรายการนั้น) หรือ `"horse:<id ม้า>"` (หน้าข้อมูลม้า) |
| `transition` | `"wipe"` `"slide"` `"fade"` `"none"` | – | ทรานซิชันตอนเปลี่ยน Active |

## ม้า (`runners[]`)

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `number` | 1–30 | (ต้องมี) | เบอร์ม้า (NO.) |
| `draw` | 1–30 หรือ `null` | `null` | ซอง ใช้เมื่อปิด "คำนวณซองอัตโนมัติ" (ถ้าเปิดไว้ จะคิดซองจากเบอร์ตามกฎ JRA) |
| `name` | string | `""` | ชื่อม้า |
| `jockey` | string | `""` | ชื่อจ็อกกี้ |
| `horseCountry` | รหัสประเทศ 2 ตัว หรือ `""` | `""` | ธงหน้าชื่อม้า |
| `jockeyCountry` | รหัสประเทศ 2 ตัว หรือ `""` | `""` | ธงหน้าชื่อจ็อกกี้ |
| `fav` | 1–30 หรือ `null` | `null` | อันดับตัวเต็ง (ขึ้นป้าย 1st, 2nd, …) |
| `scratched` | boolean | `false` | ถอนตัว (ขีดฆ่า จางลง) |
| `finish` | 1–30 หรือ `null` | `null` | อันดับที่เข้าเส้นชัย (`null` = ยังไม่มีผล ไม่ขึ้นหน้าผล) เข้าพร้อมกันใส่เลขซ้ำได้ |
| `outcome` | `"dnf"` `"dq"` หรือ `null` | `null` | ม้าที่ไม่มีอันดับ: `"dnf"` วิ่งไม่จบ, `"dq"` ถูกตัดสิทธิ์ ขึ้นหน้าผลเป็น DNF / DQ (ม้าที่ `scratched` ขึ้นเป็น SCR เอง) |
| `time` | string | `""` | เวลาที่ทำได้ เช่น `"2:24.1"` |
| `margin` | string | `""` | ระยะห่างจากตัวข้างหน้า เช่น `"1¼"`, `"½"`, `"nk"`, `"hd"`, `"nse"` (ตัวชนะเว้นว่าง) |

รหัสประเทศเป็น ISO 3166 แบบ 2 ตัวอักษร ชุดที่ dock มีให้เลือก (ตรงกับ component "flag" ใน Figma) คือ
`JP` ญี่ปุ่น, `AR` อาร์เจนตินา, `IT` อิตาลี, `BE` เบลเยียม, `US` สหรัฐฯ, `HK` ฮ่องกง, `PR` เปอร์โตริโก, `BB` บาร์เบโดส, `IE` ไอร์แลนด์, `DE` เยอรมนี, `PA` ปานามา, `GB` สหราชอาณาจักร, `FR` ฝรั่งเศส, `VE` เวเนซุเอลา, `AU` ออสเตรเลีย, `NZ` นิวซีแลนด์, `DO` โดมินิกัน, `CA` แคนาดา, `AE` สหรัฐอาหรับเอมิเรตส์, `MX` เม็กซิโก, `ZA` แอฟริกาใต้, `CL` ชิลี, `PE` เปรู
รหัสอื่นก็ใช้ได้ (ธงมาจาก flag-icons ครบทุกประเทศ) แค่ไม่อยู่ในตัวเลือกของ dock

## หน้าผลการแข่งขัน

หน้าผลแสดง POS, NO., DRAW (ถ้าเปิดไว้), HORSE, JOCKEY, TIME, MARGIN ได้สูงสุด 10 แถว เรียงตาม `finish`
แล้วต่อด้วยม้าที่ DNF, DQ และ SCR (ช่อง POS ขึ้นตัวอักษรแทนอันดับ ไม่มีเวลาและระยะห่าง)
ม้าที่ล็อค (`result.locked`) อยู่บนสุดทุกหน้าพร้อมแถบเหลือง แถวที่เหลือเปลี่ยนตามหน้า เช่น มีผล 17 ตัวและล็อค 3 อันดับแรก:
หน้า 1 = อันดับ 1–3 + 4–10, หน้า 2 = อันดับ 1–3 + 11–17 ถ้ามีหลายหน้าและ `result.auto` เปิดอยู่ (ค่าเริ่มต้น) หน้าจะวนเองทุก `result.seconds` วินาที

## ข้อมูลม้า (`horses[]`)

หน้าข้อมูลม้า: รูปม้าซ้ายจอ 1/3, ธงประเทศที่ฝึก + ชื่อม้า, "SIRE – DAM (by BMS)", O เจ้าของ / T เทรนเนอร์
หน้า 1 เป็นข้อมูลม้า หน้าต่อไปเป็นผลงานหน้าละ 7 รายการ เรียงจากใหม่ไปเก่า (เรียงให้เองตาม `date`) รูปม้าและรูปสีเสื้อไม่อยู่ในไฟล์
ตอนนำเข้าแบบเพิ่มต่อ ม้าที่ชื่อ (หรือ `id`) ตรงกับของเดิมจะถูกแทนที่ ช่องที่ต้องมีคือ `name`

| ช่อง | ชนิด | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- | --- |
| `id` | string | สร้างให้ | รหัสม้า |
| `name` | string | (ต้องมี) | ชื่อม้า |
| `trainedIn` / `bornIn` | รหัสประเทศ 2 ตัว | `""` | ประเทศที่ฝึก (ธงหน้าชื่อ) / ประเทศเกิด |
| `foaled` | `"YYYY-MM-DD"` | `""` | วันเกิด |
| `coat` | `"Bay"` `"Dark Bay"` `"Brown"` `"Black"` `"Chestnut"` `"Dark Chestnut"` `"Grey"` `"White"` หรือ `null` | `null` | สีขน (มีกรอบสีขนบนจอ) |
| `sire` / `dam` / `bms` | string | `""` | พ่อพันธุ์ / แม่พันธุ์ / พ่อของแม่ |
| `owner` / `trainer` | string | `""` | เจ้าของ / เทรนเนอร์ |
| `silks` | object หรือ `null` | `null` | สีเสื้อเจ้าของที่วาดเป็น SVG (เสื้อมีแขน): `body` สีตัว, `pattern` ลายตัว (`"plain"` `"cross"` `"sash"` `"hoops"` `"stripes"` `"halves"` `"chevron"` `"spots"`), `accent` สีลายตัว, `sleeves` สีแขน, `sleevePattern` ลายแขน (`"plain"` `"stripes"` `"hoops"`), `sleeveAccent` สีลายแขน สีเป็น `"#RRGGBB"` |
| `record` | `{ starts, first, second, third }` | 0 ทั้งหมด | สถิติ แสดงเป็น `12 (5-3-1-3)` (ตัวสุดท้าย = อันดับ 4 ลงไป คิดให้เอง) |
| `earnings` | number หรือ `null` | `null` | เงินรางวัลรวม |
| `currency` | `"JPY"` `"USD"` `"GBP"` `"EUR"` `"AUD"` `"HKD"` `"AED"` `"SAR"` `"THB"` | `"JPY"` | สกุลเงินของ `earnings` |
| `races` | อาร์เรย์ (ด้านล่าง) | `[]` | ผลงาน |
| `view` | `{ page, auto, seconds }` | `0`, `true`, `8` | หน้าที่แสดง และวนหน้าอัตโนมัติ |
